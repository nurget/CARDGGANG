# 나만의 카드깡!!

제품 소개와 사용 방법은 정식 출시를 준비할 때 언어별로 작성할 예정입니다.

## 템플릿 방향

현재 스케치·흑백·컬렉터는 사진형 초안입니다. 이후에는 색상만 바꾼 프레임 대신 주제별로 구조가 다른 템플릿을 만듭니다.

- **캐릭터 카드:** 수집형 캐릭터 카드의 재미를 참고합니다. 사진 또는 사용자가 올린 그림, 이름, 역할, 기술과 수치를 직접 편집할 수 있게 설계합니다. 기존 작품의 캐릭터·로고·카드 프레임은 사용하지 않습니다.
- **야구 카드:** 선수 카드의 정보 위계를 참고합니다. 사진, 이름, 등번호, 포지션, 시즌과 기록을 직접 입력할 수 있게 설계합니다. 공식 구단·리그 표식은 허가 없이 포함하지 않습니다.

각 주제는 실제 사진이 들어간 카드 시안을 먼저 확정한 뒤 편집 기능과 PNG 출력에 연결합니다.
